1. Project Overview

Strona internetowa postawiona z użyciem CMS: Wordpress. Do funkcjonalności sklepu internetowego użyto rozszerzenia Woocommerce. Celem projektu jest stworzenie rozbudowanego sklepu od podstaw z autorskim motywem i funkcjonalnościami. Ma on również posłużyć za modelowy projekt do budowanego portfolio oraz nauki.

2. Tech Stack

- WordPress
- WooCommerce
- PHP
- HTML5
- CSS3
- JavaScript
- Git

3. Project Structure

Główny motyw znajduje się w folderze ceo-shop, a potomny planowany jest w ceo-shop-child. Rozszerzenia można znaleźć w plugins, a zdjęcia w uploads.

4. Theme Architecture

Motyw jest autorski. W folderze assets/css znajdziemy style, assets/fonts czcionki, a wszelkie skrypty są umieszczane w assets/js.

5. Fonts & Styling

Czcionki są ładowane lokalnie, aby zapewnić optymalny czas ładowania strony. Teksty są czcionką "Lato", a nagłówki "Montserrat". Skonfigurowane są również fallbacki naprzemiennie wraz z sans-serif.

6. Version Control

Do kontroli wersji projektu użyto Git oraz na bieżąco postępy są publikowane w ramach main branch z opisami na GitHub.
